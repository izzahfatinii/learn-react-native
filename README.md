# React Native Chat Learning Project

A personal learning project built with **React Native and Expo** to explore mobile app development and experiment with building a basic chat system.

## Tech Stack

- React Native
- Expo
- JavaScript

## Features

- Basic chat interface
- Message display and interaction
- React Native component and navigation practice
- Mobile UI development using Expo

## Note

This is a learning and experimental project. Most of the data and functionality are currently hardcoded for development and practice purposes. The project is still a work in progress, with plans to integrate **AI-powered chat functionality** in the future.
